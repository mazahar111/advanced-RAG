**Title:** Methods and systems for transferring a session between audible and visual interfaces

**Abstract:** Methods and systems for transferring a user session between at least two electronic devices are described. The user session is conducted as an audible session via an audible interface provided by a primarily audible first electronic device. Input data is received from the audible interface, wherein the input data causes the audible interface to progress through audible interface states. An interaction may be determined to be sensitive or non-intuitive based on a logic rule or based on tracking interactions in the user session. A current audible interface state is mapped to a visual interface state defined for a visual interface. The mapped visual interface state is pushed to a second electronic device having a visual output device for displaying the visual interface, to enable the user session to be continued as a visual session on the second electronic device.

**Background Art:** [0003]Voice-based virtual assistants (also referred to simply as voice assistants) are software applications that use voice recognition to receive, interpret and execute audible commands (e.g., voice commands). Voice assistants may be provided by a mobile wireless communication device such as a smartphone, desktop or laptop computer, smart device (such as a smart speaker) or similar internet-of-things (IoT) device.
[0004]A drawback of voice assistants is that some interactions during a user session may be too complicated or non-intuitive to be easily conducted by audible inputs or outputs alone. Given the sequential nature of audible commands, it may be difficult for the user to identify and/or correct mistaken inputs. Another drawback is that some interactions during a user session may be involve sensitive information that should not be conducted by audible inputs or outputs.
[0005]This may be particularly the case where the voice assistant is a primarily audible device that provides an audible interface (such as a smart speaker). In such cases, the user may abandon the interaction instead of attempting the non-intuitive or sensitive interaction, since the audible interface is not suitable for the task.
